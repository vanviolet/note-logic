## Point Of AI Response

### Architecture Decision

Replaced per-card Fretboard instances (chord, family, interval — each had their own audio context, live mic, tuning state) with a **single shared Fretboard** in a **resizable bottom panel** anchored to the learn layout.

### Files Created

#### `app/shared/stores/learn-fretboard.store.ts`
- Zustand store holding all fretboard panel state.
- `selectChord(chord)`, `selectFamily(entry)`, `selectInterval(interval)` — each action computes pitchClasses, toneLabels, playableNotes, intervalNotes inline and stores flat primitives.
- Panel state: `isPanelOpen`, `panelHeight` (default 360px).
- Fretboard state: `tuning`, `activeNote`, `livePitch`.
- Audio state: `playableNotes`, `intervalNotes`, `noteGapMs`.
- Pattern: selectors like `useLearnFretboardStore(s => s.selectedId === chord.name)` ensure only the deselected + newly selected card re-render on selection change.

#### `app/routes/components/learn-fretboard-panel.tsx`
- Fixed bottom panel (`fixed bottom-0 left-0 right-0 z-30`).
- **Drag-to-resize**: `onPointerDown/Move/Up` with `setPointerCapture`; dragging the handle bar adjusts `panelHeight` in the store; min 220px, max 85% viewport height.
- **Toggle chevron** to expand/collapse without dragging.
- Collapsed height = 48px (thin strip showing selected title + subtitle).
- Panel content: Enable Audio / Play Chord / Play Interval buttons + Gap (ms) input for intervals + live pitch display.
- Single `Fretboard` (lazy via `lazyNamed`) with `enableLiveMic`, stable `onFretClick`/`handleLivePitchFrame` callbacks.
- Single `useGuitarAudio` instance — persists across route transitions.

### Performance Notes
- Cards are now ~60% lighter: no audio state, no intersection observer, no Fretboard component per card.
- `Fretboard` mounts once in the layout, not N×cards times.
- `useGuitarAudio` is a single instance — audio context created once on first Enable click.
- Zustand per-field selectors ensure minimal re-renders: only the 2 directly affected cards (prev + new selection) re-render on selection change.
