## Prompt
Refactor saja smua aplikasi ini jadi menggunakan ssr biar SEO sangat bagus

## Point OF AI Response

### Refactor dari SPA + Pre-render ke Full SSR

Aplikasi sebelumnya menggunakan `ssr: false` (SPA mode) dengan `prerender` config untuk nolopedia pages. Sekarang di-refactor ke full SSR (`ssr: true`) agar semua halaman di-render server-side per request.

### Files Modified

1. **`react-router.config.ts`** — Changed `ssr: false` → `ssr: true`, removed the entire `prerender` block. React Router v7 now runs server-side rendering on every request.

2. **`app/templates/components/theme-provider.tsx`** — Fixed SSR crash: `localStorage.getItem()` in `useState` initializer wrapped with `typeof window !== "undefined"` guard. Also guarded `window.document.documentElement` in `useEffect` and `localStorage.setItem` in the `setTheme` callback.

3. **`app/routes/nolopedia/$termId.tsx`** — Refactored to use `Route.LoaderArgs` and `Route.ComponentProps` from generated `./+types/$termId`. Component now receives `loaderData` as props (idiomatic SSR pattern) instead of re-computing via `useParams` + `DICTIONARY_MAP.get()`. Removed client-side fallback since server returns proper 404.

4. **`app/routes/nolopedia/index.tsx`** — Updated to import `Route` types from `./+types/index`. Loader now accepts `Route.LoaderArgs` and parses `request.url` search params (q, category, page) to return initial filtered/paginated data for SSR.

### SSR Benefits Achieved
- **Every page** returns full server-rendered HTML (not just nolopedia)
- **Proper HTTP status codes**: 404 for non-existent terms (verified via curl)
- **Dynamic meta tags** in `<head>` on first response (og:title, description, etc.)
- **JSON-LD structured data** included in server HTML
- **Canonical URLs** in server response
- **No JavaScript required** for crawlers to see full content
- **Existing routes** (chord, family, interval, home, tuner, studio) work with SSR out of the box — all their browser-only APIs are already in `useEffect`, `useCallback`, or event handlers

### Why It "Just Works" for Other Routes
- `useDarkMode` hook already has `typeof window === "undefined"` guards
- `useIsClient` hook returns false on server (safe)
- `useLearnSidebarStore` (Zustand) works on server
- `React.lazy()` + `Suspense` supported in React 19 SSR
- All data generation functions (`generateChordArray`, `generateIntervals`, `generateFamilyChords`) are pure — work on both server and client
- `useSearchParams` reads from the request URL on server

### Verification Results (curl tests)
- `GET /` → Full HTML with `<title>NoteLogic | Learn Music Theory</title>`
- `GET /chord` → Full HTML with Chord Explorer heading
- `GET /nolopedia` → Full HTML with JSON-LD CollectionPage, heading, card grid
- `GET /nolopedia/heavy-accent` → Full HTML with dynamic title, JSON-LD DefinedTerm + BreadcrumbList, all content sections
- `GET /nolopedia/nonexistent-term` → HTTP 404 status code
