## Prompt
Mungkin Agar UX bagus , perinterval Cardnya dan di card tersebut sudah lengkap dan ada fretbboard juga

## Point OF AI Response
- Merombak halaman Interval agar jadi **per-interval complete card** (setiap interval berdiri sendiri dalam satu kartu penuh).
- Setiap kartu kini sudah berisi komponen belajar lengkap:
  - ringkasan interval,
  - metadata (short, note result, consonance),
  - anatomy (semitone, cents, ratio, inversion),
  - function hints,
  - song references,
  - **fretboard visual** untuk root + target note interval.
- Menambahkan komponen reusable baru `interval-learning-card.tsx` agar route tetap modular dan maintainable.
- Menambahkan lazy load fretboard per card berbasis intersection observer untuk menjaga performa saat daftar kartu panjang.
- Menambahkan feedback interaktif klik note di fretboard (`Last clicked`) pada masing-masing kartu.
- Menyederhanakan halaman utama interval agar fokus ke controls + daftar kartu belajar lengkap.
- Memastikan seluruh file yang diubah bebas error lint/type.
