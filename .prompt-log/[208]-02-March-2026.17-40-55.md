## Prompt
tambahkan juga navigasi untuk transpose, misal dari caug ke daug
kemudian buat shortcut di halaman itu arrow left/right untuk pindah chord dan arrow up/down untuk navigasi transpose

## Point OF AI Response
Menambahkan navigasi transpose di halaman detail chord dengan aturan simbol chord tetap sama dan root berpindah satu langkah huruf musik (`C→D→E→F→G→A→B`), sehingga contoh `Caug` akan menuju `Daug` untuk transpose naik jika tersedia. Menambahkan tombol transpose naik/turun (ikon panah atas/bawah) di area judul chord. Menambahkan shortcut keyboard global pada halaman detail: `ArrowLeft/ArrowRight` untuk chord sebelumnya/berikutnya dalam root yang sama, serta `ArrowUp/ArrowDown` untuk transpose naik/turun. Handler keyboard mengabaikan input/textarea/select/contenteditable dan memakai navigasi route langsung ke `/chord/:id` target.
