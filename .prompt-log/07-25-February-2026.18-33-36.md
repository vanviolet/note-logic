## Prompt
masih ada chip yang text nya gak kelihatan bisakah chip ini di buat variant saja langsung di component primitivenya agar serupa semuanya

## Point Of AI Response

### Problem
Colored chips (Tonic / Subdominant / Dominant / consonance pills) were invisible in light mode because they used raw `className` strings with hardcoded `text-*-200` (light-colored) values that have no contrast on white backgrounds.

### Solution
Added 3 semantic color variants directly to the `Badge` primitive's CVA config, then migrated all call-sites to use `variant=` props.

### Changes Made

#### `app/templates/components/ui/badge.tsx`
Added three new CVA variants with proper light + dark text colors:
- `tonic` → emerald: `text-emerald-700 dark:text-emerald-300`
- `subdominant` → sky: `text-sky-700 dark:text-sky-300`
- `dominant` → violet: `text-violet-700 dark:text-violet-300`

#### `app/routes/family/lib/family-utils.ts`
Replaced `familyBadgeClass()` (returns raw className string) with `familyBadgeVariant()` (returns `"tonic" | "subdominant" | "dominant"` variant name).

#### `app/routes/family/components/family-chord-card.tsx`
Replaced `variant="outline" className={cn(familyBadgeClass(entry.family))}` with `variant={familyBadgeVariant(entry.family)}` — clean, no className override.

#### `app/routes/family/index.tsx`
Count summary badges updated from `variant="outline"` to proper `variant="tonic"`, `variant="subdominant"`, `variant="dominant"`.

#### `app/routes/interval/lib/interval-utils.ts`
Replaced `consonancePillClass()` (returns className string) with `consonancePillVariant()` (returns variant name: `"tonic"` / `"subdominant"` / `"dominant"`).

#### `app/routes/interval/components/interval-learning-card.tsx`
Replaced `variant="outline" className={cn(consonancePillClass(...))}` with `variant={consonancePillVariant(interval.consonance)}`.

### Architecture Benefit
- Single source of truth: colors live only in `badge.tsx` CVA
- All chip colors automatically correct in both light and dark mode
- No ad-hoc className overrides needed at call-sites
- Fully type-safe: variant names are `"tonic" | "subdominant" | "dominant"` literals
