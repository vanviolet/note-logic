### alphaTab Player Cursor Styling
Added CSS styles in `app/app.css` matching the screenshot reference:
- **Bar cursor** (`at-cursor-bar`): Soft yellow highlight over the currently playing bar — `rgba(255, 242, 0, 0.25)`
- **Beat cursor** (`at-cursor-beat`): Vertical purple/blue position indicator line — `rgba(100, 80, 220, 0.75)` with 3px width
- **Selection** (`at-selection div`): Transparent blue for user-selected playback range
- **Highlight** (`at-highlight *`): Primary blue fill/stroke on currently played SVG notation elements

### Dark Mode Support
- Created two surface classes: `.at-surface-dark` and `.at-surface-light` for the alphaTab host container
- Dark surface uses dark background (`#1a1a20`) with adjusted cursor opacities
- Dark surface targets SVG elements with black fill/stroke and recolors them to light (`#e4e4e4`)
- alphaTab API settings now configure `display.resources` colors based on `isDarkMode`:

- alphaTab instance re-creates when dark mode toggles (added `isDarkMode` to effect deps)
