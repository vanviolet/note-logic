## Point OF AI Response

### Dynamic Routing with Pre-rendering for Perfect SEO

Implemented `/nolopedia` (list) and `/nolopedia/:termId` (detail) routes using React Router v7's pre-rendering feature. Since the app runs with `ssr: false`, the `prerender` config in `react-router.config.ts` statically generates HTML for all 173 dictionary entries at build time — crawlers get full HTML without JavaScript.

### Files Created / Modified

1. **`react-router.config.ts`** — Added async `prerender` function that dynamically imports ALL_ENTRIES and maps each entry ID to a `/nolopedia/:id` URL path for static generation.

2. **`app/routes.ts`** — Registered `prefix("nolopedia", [...])` routes inside `site-layout` with index and `:termId` dynamic segment.

3. **`app/routes/home/home-data.ts`** — Added "Nolopedia" navigation item to NAV_ITEMS.

4. **`app/routes/nolopedia/lib/nolopedia-utils.ts`** — Shared utilities: SITE_URL, CATEGORY_LABELS (15 categories → Indonesian), DIFFICULTY_LABELS/COLORS, JSON-LD builders (DefinedTerm, BreadcrumbList, CollectionPage), filterEntries, paginate, buildPageNumbers.

5. **`app/routes/nolopedia/components/nolopedia-card.tsx`** — Card component for list grid: Link with `prefetch="intent"`, term, category badge, termId, shortDefinition, tags (max 4), guitar indicator.

6. **`app/routes/nolopedia/components/nolopedia-fallbacks.tsx`** — Skeleton loading states for search, grid, and detail page sections.

7. **`app/routes/nolopedia/index.tsx`** — List page: loader returns total count + categories; URL search params for `q`, `category`, `page`; debounced search (200ms); category filter Select with entry counts; pagination with ellipsis; JSON-LD CollectionPage; responsive grid (1/2/3 cols); PAGE_SIZE=24.

8. **`app/routes/nolopedia/$termId.tsx`** — Detail page: loader resolves entry + related terms (404 if not found); dynamic meta tags per entry (title, description, og:article, keywords); JSON-LD DefinedTerm + BreadcrumbList; canonical URL; breadcrumb nav; full template with: header (term, termId, aliases, badges), short definition highlight, detailed definition, examples list, Bravura symbol display, AlphaTex code block, guitar technique section (difficulty, hand, howTo, fretContext, tips), unicode symbol, clickable tags, related terms grid, back navigation.

### SEO Features Implemented
- **Pre-rendered static HTML** for all 173 entries at build time
- **JSON-LD structured data** (DefinedTerm, BreadcrumbList, CollectionPage schemas)
- **Dynamic meta tags** (og:title, og:description, og:type, og:url, twitter:card, canonical, keywords)
- **Semantic HTML** with proper heading hierarchy
- **Breadcrumb navigation** matching schema.org BreadcrumbList
- **Canonical URLs** per page
- **`prefetch="intent"`** on links for instant navigation

### Technical Decisions
- Used dynamic import in `react-router.config.ts` because static imports from app code don't resolve in config context
- Imported types from `~/theory-music/dictionary/types` (not barrel) to avoid IDB resolution in non-browser context
- Used `useParams` + `DICTIONARY_MAP` client-side instead of generated `Route.ComponentProps` types (which require dev server to generate `+types` first)
- Badge variant `"subdominant"` chosen for category badges (valid variant in project's Badge component)
