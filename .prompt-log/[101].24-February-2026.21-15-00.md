## Root Cause Analysis

Dilakukan audit menyeluruh terhadap `buildNoteLevelToken` dan `buildBeatLevelToken` di `studio-utils.ts`. Hasilnya:

### Beat-level (via `buildBeatLevelToken`) — salah posisi di UI:
| Field | AlphaTex Token | Status Sebelum |
|-------|---------------|----------------|
| `duration` | `.${n.duration}` pada beat | ❌ di NoteCellPopover (per-note) |
| `dynamic` | `dy ${n.dynamic}` | ❌ di NoteCellPopover (per-note) |
| `vibrato` | `v` / `vw` via `buildBeatLevelToken` | ❌ di NoteCellPopover Tab FX + updateNoteById propagasi note-level |

### Note-level (via `buildNoteLevelToken`) — sudah benar:
`noteEffect`, `isPalmMute`, `isLetRing`, `isStaccato`, `isBend`, `harmonicType`, `isTied`, `isGhost`, `isLeftHandTap`, `accent`, `ornament`, `pickSlide`, `slideIn`, `slideOut`

## Changes Made

### `app/routes/studio/hooks/use-studio-note-actions.ts`
- **Removed** `vibrato` dari note-level section di `updateNoteById`
- **Added** `vibrato` ke beat-level section (propagates to all notes at same beat)

### `app/routes/studio/components/studio-grid.tsx`
1. **`hasBeatEffects()`** — tambah check `note.vibrato !== "none"`
2. **`BeatColumnPopover`** — tambah 3 section baru di atas "Beat FX":
   - `Duration` (2-col grid bersama Dynamic)
   - `Dynamic` (2-col grid bersama Duration)
   - `Vibrato (Beat)` (standalone section)
3. **`NoteCellPopover` Tab "Note"** — hapus grid Duration+Dynamic, ganti dengan info hint:
   ```
   🎛 Duration, Dynamic & Vibrato are beat-level — edit via the ruler
   ```
4. **`NoteCellPopover` Tab "FX"** — hapus section Vibrato, perbaiki dead note banner text (`"vibrato, ornament"` → `"ornament"`), jadikan Ornament standalone (tidak lagi dalam 2-col grid)

## Architecture Result

**`BeatColumnPopover` (ruler cell icon)** → semua beat-level:
- Duration, Dynamic, Vibrato
- Beat FX, Tuplet, Tremolo, Grace Note
- Stroke, Arpeggio, Wah Pedal
- Fermata, Octave Shift
- Chord Name, Beat Text

**`NoteCellPopover` (klik note)** → hanya note-level:
- Tab 🎵 Note: info hint → Harmonic, Note FX, Accent → Note Flags
- Tab 🎸 FX: Techniques (PM, LR, Staccato, Dead, Bend) → Ornament → Slides (In/Out/Pick)
