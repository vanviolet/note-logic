## Prompt
Buat Tampilan Tuner agar lebih UX, buat ada seperti effect carousel note nya , dan ketika nada sesuai maka akan effect carousel akan berhenti di nada itu dan sementara nada 100 sesuai maka akan ada effect bergoyang di note itu dan warna pembedannya

## Point OF AI Response
- Menambahkan UX visual baru berupa **Note Carousel** pada tuner, menampilkan deretan nada kromatik di sekitar target.
- Carousel bergerak saat proses tuning belum pas (mode scanning), lalu **lock/berhenti di nada target** saat status sudah `In Tune`.
- Menambahkan status **Perfect Tune** (akurasi sangat tinggi) dengan kriteria cents sangat dekat 0 dan confidence tinggi.
- Saat `Perfect Tune`, note target mendapat **efek bergoyang** khusus + warna pembedaan (hijau/emerald glow) agar feedback lebih jelas.
- Menambahkan pembedaan visual state lain: target normal, focused note, in-tune, dan perfect-tune.
- Menambahkan animasi CSS khusus tuner (`tuner-note-carousel-run`, `tuner-note-perfect`) serta dukungan `prefers-reduced-motion` agar aksesibel.
- Mengirim data midi target/detected dari halaman tuner ke komponen meter untuk pemetaan carousel yang presisi.
