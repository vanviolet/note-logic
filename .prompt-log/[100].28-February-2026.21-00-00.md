## Prompt
Tambahkan fitur agar bisa melihat fingerpicking-nya di chord diagram, entah ketika di hover atau ketika di klik muncul dialog.

## Point OF AI Response

### Files Created
1. **`app/routes/songbook/lib/fingerpicking-patterns.ts`** – Library berisi:
   - Tipe data (`RHFinger`, `PickStep`, `FingerpickingPattern`, `FingerAssignment`)
   - Logika penempatan jari kanan otomatis untuk guitar & ukulele (`getGuitarFingerAssignment`, `getUkuleleFingerAssignment`)
   - 7 pola fingerpicking guitar (Travis, Arpeggio Naik, Arpeggio Naik-Turun, Dust in the Wind, p-i-m-a Klasik, Pinch Pattern, Waltz 3/4)
   - 5 pola fingerpicking ukulele (Arpeggio Naik, Arpeggio Naik-Turun, Pinch & Roll, Travis Style, Waltz 3/4)
   - Helper `resolvePatternForVoicing` untuk menyesuaikan pattern ke string yang dimainkan
   - Color constants per finger (p=pink, i=blue, m=green, a=amber)

2. **`app/routes/songbook/components/fingerpicking-dialog.tsx`** – Dialog component berisi:
   - Visual penempatan jari kanan per string (warna per jari: p, i, m, a)
   - Pattern selector (tombol per pola)
   - Timeline grid (tabel string × step) dengan warna per jari
   - Animasi preview: tombol Play untuk melihat urutan petikan berjalan live
   - Legend warna jari kanan
   - Teks step-by-step di bawah grid

### Files Modified
3. **`app/routes/songbook/components/chord-diagram.tsx`** – Ditambah ikon tangan kecil di bawah diagram. Klik membuka FingerpickingDialog dengan instrument="guitar".
4. **`app/routes/songbook/components/ukulele-chord-diagram.tsx`** – Sama seperti guitar, ikon tangan membuka FingerpickingDialog dengan instrument="ukulele".

### UX Flow
- Setiap chord diagram (guitar & ukulele) sekarang punya ikon tangan kecil di bawah.
- Klik ikon → Dialog terbuka menampilkan:
  1. Penempatan jari kanan (p/i/m/a) per string
  2. Pilihan pola fingerpicking
  3. Grid visual timeline (string × beat)
  4. Tombol animasi preview
  5. Legend warna

### Technical Notes
- Pattern menggunakan generic string index yang di-resolve ke string yang benar-benar dimainkan per voicing
- Dialog menggunakan shadcn Dialog (Radix) yang sudah ada di project
- Animasi preview menggunakan `setInterval` dengan cleanup (bukan state per frame, sesuai performance rules)
- Zero TypeScript errors, zero lint errors
