## Prompt
Lanjutkan membuat halaman Interval, buat UI semenarik mungkin, UX juga harus bagus agar mudah untuk belajar

## Point OF AI Response
- Membuat halaman baru `Interval Explorer` dengan UI interaktif dan konsisten dengan shell aplikasi (background/header/footer).
- Menambahkan route `/interval` dan memasukkan menu `Interval` pada navigasi utama.
- Menyusun kontrol belajar yang mudah dipakai:
  - pilih `Root Note`,
  - pilih mode enharmonic `Spelling` (auto/sharp/flat),
  - pencarian cepat,
  - filter kategori lewat tabs (`All`, `Perfect`, `Imperfect`, `Dissonance`).
- Menambahkan kartu detail interval aktif untuk pembelajaran terstruktur:
  - ringkasan identitas interval,
  - note hasil dari root,
  - inversion,
  - semitone/cents/ratio,
  - function hints,
  - song references.
- Menyediakan grid kartu interval yang bisa diklik untuk fokus belajar per interval, dengan progress distance visual.
- Menampilkan statistik ringkas jumlah kategori interval agar user cepat memahami distribusi materi.
- Seluruh file yang diubah telah dicek dan bebas error type/lint pada scope perubahan.
