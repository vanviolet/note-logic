## Prompt
Kenapa filter root berbeda beda di module Chord family,dan interval,  apakah ada alasanya, jika memang tidak maka samakan ,dan harus lengkap,
kemudian tambahkan di setiap chord ChordDiagram seperti di songbook nya di halaman chord

## Point OF AI Response
Filter root memang sebelumnya tidak konsisten karena masing-masing modul memakai source berbeda dan ada pemotongan daftar root (slice 12) di Chord dan Interval. Saya samakan dengan source root tunggal lintas modul agar lengkap dan konsisten.

Perubahan utama:
- Tambah konstanta root bersama di app/shared/constants/music.ts (`ROOT_FILTER_OPTIONS`).
- Chord root filter kini memakai daftar root lengkap dari konstanta (tidak lagi tergantung turunan data + tidak dipotong).
- Interval root filter kini memakai daftar root lengkap yang sama (hapus pemotongan 12 item).
- Family root filter kini memakai daftar root lengkap yang sama untuk major/minor.
- Tambahkan `ChordDiagram` pada setiap item chord di halaman Chord:
  - Di kartu chord (cards view).
  - Di detail baris expand pada table view.
