## Point OF AI Response

### DOM-Based Playhead Highlighting (Performance-Safe)
Instead of passing `playheadBeat`/`playingNoteIds` through React props to every cell (which would re-render thousands of cells on every beat), the highlighting is done via **direct DOM manipulation**:
- Added `data-abs-beat` attribute to every grid cell and ruler cell
- Added `data-note-btn` attribute to note buttons inside cells
- A single `useEffect` in `StudioGrid` watches `playheadBeat` and `playingNoteIds`, uses `querySelectorAll` to toggle CSS classes
- Cleanup function removes all highlight classes on effect cleanup or unmount

### Visual Behavior
- **Column highlight**: All cells in the current beat column get `.studio-cell-playing` — soft blue background + border glow + pulse animation
- **Note highlight**: Specific note buttons being played get `.studio-note-playing` — stronger blue fill, border, glow shadow
- **Auto-scroll**: When playing notes exist, the first cell in the current beat column scrolls into view smoothly
- **Dark mode**: Darker purple/indigo tones for dark theme via `.dark .studio-cell-playing` / `.dark .studio-note-playing`
- **Reduced motion**: Both classes have `animation: none` for `prefers-reduced-motion`

### Files Modified
- `app/routes/studio/components/studio-grid.tsx` — Added data attributes to cells, DOM-based highlight effect
- `app/app.css` — Added `.studio-cell-playing`, `.studio-note-playing`, `@keyframes studio-beat-pulse`, dark mode variants
