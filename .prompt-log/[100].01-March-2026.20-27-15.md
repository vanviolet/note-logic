## Prompt
Research the codebase to understand patterns for building a new module. Requested: route structure, navigation, nolopedia list+detail pattern, theory data pattern, cross-reference system, shared components, and learn layout sidebar.

## Point OF AI Response
Comprehensive research of 7 areas covering the full module-building pattern:

1. **Route structure** (`routes.ts`): Uses `layout()`, `prefix()`, `route()`, `index()` from `@react-router/dev/routes`. Site-layout wraps everything except `/studio`. Learn-layout wraps `/family` and `/interval` with shared fretboard panel.

2. **Navigation** (`home-data.ts`): Single source of truth with `NAV_GROUPS` (3 groups: Belajar, Referensi, Tools), `CORE_FEATURES`, `LEARNING_PATHS`, `UPCOMING_MODULES`. Header consumes these for desktop NavigationMenu and mobile collapsible groups.

3. **Nolopedia pattern**: Server loader with URL search param filtering + pagination (PAGE_SIZE=24). Detail page resolves by `params.termId` from `DICTIONARY_MAP` + user entries. Card component uses shadcn Card with Link wrapper.

4. **Theory data**: `primitives.ts` is single source of truth for pitch classes/notes. Barrel export from `core/index.ts`. Dictionary types are flat, JSON-serializable with rich optional fields.

5. **Cross-reference system**: `MusicEntityRef` typed pointers with `entityToRoute()` for routing. Factory functions (`chordRef`, `intervalRef`, etc.). Pure computation functions in `cross-ref.ts` for deriving relationships.

6. **UI components**: 47 shadcn components available. Standard Radix primitive wrapping pattern with `cn()` utility.

7. **Sidebar system**: Zustand stores for sidebar (`learn-sidebar.store.ts`) and fretboard panel (`learn-fretboard.store.ts`). `FloatingFilterSidebar` component provides fixed-right filter panel consumed per-route.
