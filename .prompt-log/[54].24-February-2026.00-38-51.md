## Prompt
highlight editor masih tidak jalan ketika di play

## Point OF AI Response

### Root Cause
The grid highlight was going through a React state pipeline: `activeBeatsChanged` → `setPlayheadBeat()` / `setPlayingNoteIds()` → React re-render → `useEffect` → DOM manipulation. This async chain through React's render cycle was too slow and unreliable — by the time the effect ran, the beat had already advanced.

### Fix: Direct DOM Manipulation from Event Handler
Bypassed React state entirely for the grid highlighting:
- Added `gridContainerRef` parameter to `useAlphaTab` hook
- In `activeBeatsChanged` event handler, directly query the grid container DOM and toggle `.studio-cell-playing` / `.studio-note-playing` CSS classes
- This happens synchronously in the event callback — zero React overhead, immediate visual update
- Removed the `useEffect`-based highlighting from `StudioGrid` entirely

### Also Added
- Grid highlights are cleared when Stop is pressed (direct DOM cleanup in `stopPlayback` callback)
- `StudioGrid` no longer destructures `playheadBeat` / `playingNoteIds` (they remain in props type for compatibility but highlighting is handled externally)

### Files Modified
- `app/routes/studio/hooks/use-alpha-tab.ts` — Added `gridContainerRef` param, direct DOM highlighting in `activeBeatsChanged`
- `app/routes/studio/components/studio-grid.tsx` — Removed `useEffect`-based highlighting, kept data attributes
- `app/routes/studio/index.tsx` — Added `gridContainerRef`, passed to hook, wrapped grid in ref'd div, clear highlights on stop
