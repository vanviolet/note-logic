## Prompt
Saya ingin ada fitur agar bisa menambah dictionary, atau pun song book, coba analisa, apakah ini harus di refactor codenya menjadi json untuk dictionary dan song book atau bisa tetap awalnya default tapi ada tambahan dari json, terserah bagaimana boleh refactor boleh tidak silahkan implementasikan sebaik mungkin

## Point OF AI Response

### Keputusan Arsitektur: Hybrid Approach (Keep TS defaults + JSON overlay)

**Alasan tidak refactor ke pure JSON:**
- 15+ file data TypeScript existing memberikan type safety yang bagus
- Refactoring besar = breaking change yang tidak perlu
- TS data tetap sebagai "built-in" yang immutable, JSON hanya untuk user-added

### File Baru yang Dibuat:

1. **`data/user-dictionary.json`** — Empty JSON array, menyimpan entri dictionary dari user
2. **`data/user-songbook.json`** — Empty JSON array, menyimpan lagu dari user
3. **`app/lib/json-db.server.ts`** — Server-only CRUD utility (read/write/insert/delete) menggunakan Node.js `fs`. Ditandai `.server.ts` agar build gagal jika bocor ke client.
4. **`app/lib/chord-sheet-parser.server.ts`** — Parser untuk mengubah plain-text ChordPro format menjadi `SongSection[]` + `chordsUsed[]`
5. **`app/routes/nolopedia/components/add-entry-dialog.tsx`** — Dialog form untuk menambah istilah musik baru (term, category, definition, examples, tags, dll)
6. **`app/routes/songbook/components/add-song-sheet.tsx`** — Sheet (side panel) form untuk menambah lagu baru dengan ChordPro chord sheet parser

### File yang Dimodifikasi:

1. **`app/routes/nolopedia/index.tsx`** — Loader merge built-in + user entries. Server `action` untuk insert/delete. UI: tombol "Tambah Istilah", badge "User" pada entri user, tombol hapus.
2. **`app/routes/songbook/index.tsx`** — Loader merge built-in + user songs. Server `action` untuk insert/delete. UI: tombol "Tambah Lagu", badge "User", tombol hapus.
3. **`app/routes/nolopedia/$termId.tsx`** — Loader juga lookup ke user entries jika tidak ditemukan di built-in.
4. **`app/routes/songbook/$songId.tsx`** — Loader juga lookup ke user songs jika tidak ditemukan di built-in.

### Alur Data:
```
Built-in TS Data (immutable) ─┐
                               ├─ Merge di Loader (server) ─→ Component
User JSON Data (mutable) ─────┘
                                         ↑
                            action (insert/delete) ─→ Revalidate semua loader
```

### Key Features:
- **Zero breaking change** — semua existing code tetap berjalan
- **Auto-revalidation** — setelah action (add/delete), React Router otomatis refresh loader data
- **User badge** — entri dari user ditandai badge "User" biru + tombol hapus
- **ChordPro parser** — user cukup paste chord sheet format standar, auto-parse ke sections
- **Type safe** — semua user entries mengikuti DictionaryEntry / SongEntry type yang sama
- **Build verified** — `tsc --noEmit` dan `react-router build` sukses tanpa error
