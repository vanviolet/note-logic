## Prompt
Banyak fitur yang tidak dapat diklik — ketika diklik tidak berubah. Apakah ada validasi?
Jika ada validasi munculkan toast. Jika fitur tidak tersedia untuk note tertentu, hide fiturnya.
Beat effect bukan per note tapi per column, jangan semua ditaruh di popover.
Analisa semuanya dan kondisikan tampilannya — atau ada button baru di setiap column.

## Root Causes Found

### 1. `updateNoteById` Ignored All New Fields (Primary Bug)
`use-studio-note-actions.ts` `updateNoteById` had a narrow `Partial<Pick<StudioNote, ...>>` type that
only listed 13 original fields. All 19 new fields added in the previous session (`harmonicType`, `accent`,
`ornament`, `isTied`, `isGhost`, `isLeftHandTap`, `pickSlide`, `tuplet`, `tremoloMark`, `graceType`,
`fermata`, `octaveShift`, `wahMode`, `strokeType`, `arpeggioType`, `chordName`, `beatText`,
`trillFret`, `trillSpeed`) were silently ignored — the update function received them but discarded them.

### 2. New Notes Missing Default Fields
`addOrSelectCell` and `useStudioKeyboard` created new notes without the new fields, causing `undefined`
values that re-introduced the AlphaTex parsing bug for freshly created notes.

### 3. Beat-Level Features Were Per-Note in UI
`beatEffect`, `tuplet`, `tremoloMark`, `graceType`, `fermata`, `octaveShift`, `wahMode`,
`strokeType`, `arpeggioType`, `chordName`, `beatText` are beat-level in AlphaTex (applied to whole
chord column). But they were buried in each note's popover, meaning changes on non-first notes of a
chord were silently ignored in the rendered output.

### 4. No Contextual Hiding for Dead Notes
Dead notes (`isDead=true`) showed pitch-specific controls (harmonic type, trill, bend, slides,
vibrato, ornament, pick slide) that don't produce any output for dead notes.
