## Prompt
Container halaman tuner belum sesuai dengan halaman yang lain jadi tidak konsisten.
- Perbagus halaman tuner
- Percantik progress tuner entah menggunakan icon atau apa
- Gunakan background neon dan starfield dihalaman tuner tampilan mirip seperti di home hero

## Points of AI Response

### 1. `app/routes/tuner/index.tsx` — Hero section dengan Neon + Starfield
- Dibungkus `<section className="relative w-full">` konsisten dengan pola page lain.
- Ditambahkan hero banner di atas konten dengan `relative overflow-hidden border-b border-border/50`.
- Dark mode detection menggunakan `useIsClient` + `useTheme` (sama persis dengan pola `home-theme.ts`).
- Untuk dark mode: `NeonBackground` (4 rings, merah/pink), `StarfieldBackground` (180 stars, `#fc8096`), dan `Particles` (28 particles, opacity 30%) — sama persis seperti `HomeHero`.
- Overlay gradient: `radial-gradient(circle_at_top, primary/0.22)` + `bg-linear-to-b from-primary/10` (konsisten dengan home hero).
- `h1` dan deskripsi dipindah ke dalam hero `div` dengan `z-10` agar tampil di atas background effects.
- Konten utama (TunerMeter) diletakkan di luar hero dalam container `max-w-6xl`.

### 2. `app/routes/tuner/components/tuner-meter.tsx` — Enhancements
- **Kartu wrapper**: ditambah `backdrop-blur-sm shadow-lg`, border reaktif: `border-emerald-500/50` saat perfect tune, `border-emerald-400/30` saat in tune, `border-border/60` default.
- **Target String row**: ditambah `<Music2>` icon dalam kotak rounded, layout lebih rapi.
- **Status Badge**: 
  - Perfect tune → warna emerald, icon `<CheckCircle2>`.
  - In Tune → warna emerald lebih transparan + icon.
  - Tune Up/Down → teks dengan panah.
- **Mic badge**: icon `<Mic>` dengan `animate-pulse` saat isListening.
- **Analog gauge**: border reaktif emerald saat isPerfectTune, gradient `from-primary/12`.
- **Needle**: warna + glow berbeda per state — emerald glow saat in tune, brighter glow saat perfect, primary glow default.
- **Detected label**: ditambah `<Activity>` icon di header, warna teks reaktif emerald.
- **Confidence / Stability**: `<Progress>` bar DIGANTI dengan `ConfidenceBars` — komponen LED signal-strength (10 bar dengan tinggi progresif). Warna: merah (1–3) → amber (4–6) → lime (7–8) → emerald (9–10), masing-masing dengan neon glow `shadow-[0_0_4px_rgb(...)]`.

### Konsistensi yang dicapai
- Layout container `max-w-6xl` konsisten dengan Chord/Family/Interval pages.
- Hero banner pattern identik dengan `HomeHero` (neon + starfield + radial overlay).
- Dark/light mode detection via `useTheme` + `useIsClient` (pattern yang sama).
- Tidak ada perubahan ke routing, hooks, atau CSS global.
