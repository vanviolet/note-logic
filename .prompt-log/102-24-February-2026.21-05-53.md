## Prompt

"Apakah ada fitur lain di alpha tex, mungkin yang selain note level atau beat level, seperti tuning, instrument dll, coba analisa dan implementasikan dengan baik, buat UI yang bagus"

## Points of AI Response

### Analysis
AlphaTex has features beyond note/beat level that were entirely hardcoded or absent in the studio:
- **Score-level tags**: `\subtitle`, `\artist`, `\album`, `\words`, `\music`, `\copyright` — all missing
- **Track-level tags**: `\track "name" { instrument "..." }` — name and instrument were hardcoded to `"Guitar"` / `"Acoustic Guitar (steel)"`; `\capo N` — absent; `\ks KEY` — absent

### Implementation

#### `app/routes/studio/types.ts`
- Added `KeySignature` union type (15 keys: C major through all sharps/flats)
- Added `ScoreSettings` interface with: `subtitle`, `artist`, `album`, `words`, `music`, `copyright`, `trackName`, `instrument`, `capo`, `keySignature`
- Added `DEFAULT_SCORE_SETTINGS` constant

#### `app/routes/studio/lib/studio-utils.ts`
- Added `scoreSettings?: Partial<ScoreSettings>` as optional 8th parameter to `toAlphaTex()`
- Now generates `\subtitle`, `\artist`, `\album`, `\words`, `\music`, `\copyright` when provided
- Track line uses `scoreSettings.trackName` and `scoreSettings.instrument` (with fallback defaults)
- Generates `\capo N` when capo > 0
- Generates `\ks KEY` when key is not C

#### `app/routes/studio/components/studio-score-settings-panel.tsx` (NEW)
- Card component with 2 tabs: **Track** + **Score Info**
- **Track tab**: Track Name input, Capo toggle (0–7), Key Signature 15-button grid, Instrument grouped Select with custom input fallback
- **Score Info tab**: Subtitle, Artist, Album, Music by, Lyrics by, Copyright fields in 2-column grid + live AlphaTex preview when any field filled
- Header badges: "Score Info" badge when metadata filled; "Track Custom" badge when non-default track settings
- 7 instrument groups: Guitar, Bass, Lead, Piano/Keys, Strings, Woodwind/Brass, Percussion

#### `app/routes/studio/index.tsx`
- Added `scoreSettings` state initialized to `DEFAULT_SCORE_SETTINGS`
- Passed as 8th arg to `toAlphaTex()` in `useMemo`
- Passed `scoreSettings` + `onChangeScoreSettings` down to `StudioMainContent`
- Fixed pre-existing unused `scoreSource` (renamed to `_scoreSource`)

#### `app/routes/studio/components/studio-main-content.tsx`
- Added `scoreSettings: ScoreSettings` and `onChangeScoreSettings` to `StudioMainContentProps`
- Renders `<StudioScoreSettingsPanel>` in the main content column after the grid

### Issues Resolved
- Unicode `♭`/`♯` in JSX caused parse error → replaced with ASCII `b`/`#`
- Multiple Prettier/ESLint formatting issues in the new panel component fixed iteratively
- Pre-existing unused `scoreSource` variable prefixed with `_` to satisfy lint rule
