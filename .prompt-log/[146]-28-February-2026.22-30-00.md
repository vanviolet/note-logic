## Prompt
Refactor module chord agar seperti module Dictionary/nolopedia: SEO bagus, dynamic routing, data dengan ID, sorting (C sebelum C5/Cm dulu), dan input untuk tambah chord yang disimpan di file JSON.

## Point OF AI Response

### Perubahan Arsitektur

1. **Dynamic Routing** — Route chord diubah dari single route `route("chord", ...)` menjadi prefix-based `...prefix("chord", [index, route(":chordId", ...)])` di `routes.ts`, mengikuti pola nolopedia.

2. **ChordEntry + id** — Field `id: string` ditambahkan ke `ChordEntry` di `chord.tsx`. ID di-generate via `chordNameToId(root, symbol)` yang menghasilkan slug URL-friendly (contoh: `c-sharp-m7b5`).

3. **Static Exports** — `ALL_CHORDS`, `CHORD_MAP`, `CHORD_FAMILIES`, `CHORD_QUALITIES` di-export sebagai konstanta static dari `chord.tsx` untuk SSR.

4. **Sorting** — `getChordSortWeight()` memberi weight berdasarkan urutan definisi SYMBOLS, sehingga saat filter root C, urutan menjadi: C → Cm → Cdim → Caug → C5 → Csus2 → ... (simpler first).

5. **SSR List Page** (`chord/index.tsx`) — Menggunakan `loader` + `action` pattern seperti nolopedia. Server renders page berdasarkan search params (q, root, family, quality, page). JSON-LD CollectionPage, canonical URL, full meta tags.

6. **SSR Detail Page** (`chord/$chordId.tsx`) — Loader fetches chord by ID dari `CHORD_MAP` atau user entries. Full SEO: JSON-LD DefinedTerm, BreadcrumbList, dynamic meta tags, canonical URL, 404 handling.

7. **Add Chord Dialog** (`add-chord-dialog.tsx`) — Form dialog untuk menambahkan chord custom. Data disimpan ke `data/user-chords.json` via server action.

8. **JSON DB** — `json-db.server.ts` diperluas dengan `getUserChordEntries()`, `addUserChordEntry()`, `deleteUserChordEntry()`.

### File yang Dibuat/Diubah

- `app/theory-music/chord.tsx` — id field, chordNameToId, getChordSortWeight, ALL_CHORDS, CHORD_MAP static exports
- `app/lib/json-db.server.ts` — Chord CRUD functions
- `app/routes/chord/lib/chord-utils.ts` — SEO helpers, filter, sort, paginate, JSON-LD builders
- `app/routes/chord/index.tsx` — Full SSR list page with loader/action/meta
- `app/routes/chord/$chordId.tsx` — SSR detail page with fretboard, diagrams, voicing, cross-links
- `app/routes/chord/components/chord-card.tsx` — New card component linking to detail page
- `app/routes/chord/components/add-chord-dialog.tsx` — Add chord dialog
- `app/routes.ts` — Updated to prefix-based chord routing
- `data/user-chords.json` — Empty JSON array for user chords
