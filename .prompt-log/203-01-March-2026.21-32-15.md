## Prompt
Research task: understand how AlphaTab is currently used in this project — package version, initialization, playback, wrappers, AlphaTex usage, rendering pattern.

## Point OF AI Response
Comprehensive audit of AlphaTab integration across the codebase:

- **Package**: `@coderline/alphatab` ^1.8.1 + `@coderline/alphatab-vite` ^1.8.1
- **Vite plugin**: `alphaTab()` registered in vite.config.ts for worker/font handling
- **Single-page usage**: Only `app/routes/studio/` uses AlphaTab; songbook & sight-reading do NOT use it
- **Core hook**: `use-alpha-tab.ts` — dynamically imports `@coderline/alphatab`, creates `AlphaTabApi` instance, manages lifecycle
- **Settings**: font dir `/font/`, soundfont `/soundfont/sonivox.sf3`, cursor/highlighting enabled, dark mode color resources
- **Rendering**: `api.tex(alphaTex)` for editor-generated content; `api.renderScore(score, trackIndexes)` for imported GP files
- **Playback**: `api.playPause()`, `api.stop()`, `api.tickPosition` for seeking; track volume via `api.changeTrackVolume()`
- **AlphaTex generation**: `toAlphaTex()` and `toMultiTrackAlphaTex()` in studio-utils.ts convert StudioNote[] to AlphaTex strings
- **GP import**: `alphaTab.importer.ScoreLoader.loadScoreFromBytes()` in use-studio-project.ts
- **Host element**: `<div ref={alphaHostRef}>` in studio-preview-panel.tsx with CSS classes `at-surface-dark`/`at-surface-light`
- **Type interface**: `AlphaTabApiLike` in types.ts — thin type for tex/renderScore/playPause/stop/destroy/events
