## Point OF AI Response
Fitur live mic tracking untuk fretboard sudah ditambahkan dengan pipeline yang diminta dan fokus performa:

1) Pipeline audio real-time (sesuai urutan)
- Mic (`getUserMedia`)
- Web Audio API (`AudioContext`)
- Noise filter (`BiquadFilter`: high-pass + low-pass)
- Pitch detection (`pitchfinder` dengan YIN)
- Smoothing (EMA pada frekuensi)
- Stabilization lock (frame lock sebelum emit note stabil)
- Mapping ke fret (berdasarkan MIDI ke tombol fret yang punya `data-midi` sama)

2) Efek visual bergerak/warna/bergoyang di fretboard
- Saat note stabil terdeteksi, posisi fret terkait diberi efek highlight + pulse + shake.
- Efek diterapkan via manipulasi DOM (class toggle + CSS var) agar minim rerender React.

3) Performa dioptimalkan
- Update real-time berjalan di `requestAnimationFrame` dengan `AnalyserNode`.
- Tidak ada rerender per-frame ke React state untuk highlight; langsung DOM query dan class update.
- React state hanya untuk status ringan (start/stop/error mic).

4) Siap untuk fitur tuner
- Data pitch frame diekspos sebagai payload terstruktur (`LivePitchFrame`) berisi:
  - frequency
  - smoothedFrequency
  - midi
  - cents
  - note
  - octave
  - confidence
  - timestamp
- Fretboard menyediakan callback `onLivePitchFrame` untuk dipakai tuner di langkah berikutnya.

5) Kontrol mic di fretboard
- Ditambahkan tombol `Start Live Mic` / `Stop Live Mic` langsung di komponen fretboard.
