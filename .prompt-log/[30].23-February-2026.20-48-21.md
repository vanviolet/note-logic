boleh buatkan collapse kemudian sama seperti di halaman chord buat fretboard interactive bisa bersuara, start live mic, dan juga fitur play interval yang ada settigan berapa ms jarak antara nadanya default 0,44 ms saja

## Point OF AI Response
- Menambahkan fitur **collapse/expand** pada setiap `IntervalLearningCard` agar UX lebih rapi saat daftar interval panjang.
- Menambahkan interaksi fretboard setara halaman chord:
  - klik note di fretboard memutar suara note,
  - highlight note aktif,
  - tuning bisa diubah,
  - live mic pitch aktif pada fretboard card interval.
- Menambahkan feedback live pitch (note, octave, frequency, cents) di dalam card.
- Menambahkan kontrol audio per card:
  - `Enable Audio`,
  - `Play Interval` (mainkan root lalu target interval berurutan).
- Menambahkan setting jarak antar nada interval berbasis **milliseconds** dengan default `440 ms` (`0.44s`) sesuai request.
- Menjaga performa dengan lazy-load fretboard berbasis intersection observer.
- Memastikan file yang diubah bebas error lint/type.
