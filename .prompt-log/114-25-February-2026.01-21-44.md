## Prompt
Tambahkan menu di header namanya Effect, kalau di klik akan muncul interactive window. Isinya semua fitur effect (harmony, note fx, accent, teknik, ornament, beat, duration, dynamic, tuplet, stroke dll). Pisahkan section: atas untuk beat-level, bawah untuk note-level. Semua item bisa di drag ke editor grid. Beat-level drag mempengaruhi seluruh beat column, note-level harus ke note tertentu. Ada visual drag effect.

### Architecture Decisions
- Used HTML5 Drag and Drop API (not pointer events) for cross-window dragging since the interactive window renders via `createRoot` outside the React tree
- Effect items carry `patch: Record<string, unknown>` that maps directly to `StudioNote` fields
- Beat-level effects query all cells matching `data-abs-beat` to highlight/patch entire beat column
- Note-level effects require targeting a specific `data-note-btn` / `data-note-id` element
- Visual feedback: body class `studio-effect-dragging` + `data-effect-level` attribute for global CSS hints
