## Prompt

- Ketika drag resize terasa agak berat, dan ketika drag cepat ada delay patah
  apakah anda sudah menggunakan interactjs atau react-resizable-panel, atau anda lupa tentang performa

- kemudian ketika klik card seperti ada delay, apakah karena mengirim data ke store atau memang animation,
  buat agar lancar dan tidak terasa ada delay bagaimana pun caranya

## Root Cause Analysis

### Drag heaviness
Every `pointermove` called `setPanelHeight(next)` → Zustand state update → full React re-render of
`LearnFretboardPanel` (including fretboard subtree, Suspense boundary, all store selectors). At 60fps
this is ~60 re-renders/second on a complex component.

### Card click delay
Two causes:
1. `ring-2 ring-primary/60` was inside `transition-[box-shadow,border-color]` — the ring CSS
   (which is `box-shadow` internally) was being animated with a 150ms delay, so selection feedback
   appeared slow.
2. `LearnContentWrapper` subscribed to `panelHeight` and `isPanelOpen` from Zustand. When a card was
   clicked and the panel opened, this caused a heavy re-render + synchronous layout reflow.

## Point of AI Response

### Fix 1 — Drag: DOM-direct + rAF throttle (zero React re-renders during drag)

**`app/routes/components/learn-fretboard-panel.tsx`**

- Added `panelRef = useRef<HTMLDivElement>()` — direct ref to the outer panel div.
- Added `rafRef = useRef<number | null>(null)` — rAF handle to throttle pointermove.
- Updated `dragRef` type to include `pendingHeight` (tracks latest height without React state).
- `handleDragStart`: suspends CSS transitions (`panelRef.current.style.transition = "none"`) so
  the panel tracks the pointer with zero lag.
- `handleDragMove`: **rAF-gated** (skips if a frame is already pending); writes
  `panelRef.current.style.height` and `document.documentElement.style.setProperty("--learn-panel-h", ...)`
  directly — **zero Zustand calls, zero React re-renders** during the entire drag gesture.
- `handleDragEnd`: cancels in-flight rAF, restores transitions (`style.transition = ""`), then
  commits the final height to the Zustand store **once**. Snap-close logic preserved.
- Removed `setPanelHeight` and `openPanel` from Zustand selector subscriptions (now only accessed
  via `getState()` in `handleDragEnd`).
- Panel outer div gets `ref={panelRef}` and `transition-[height,right] duration-200 ease-out` for
  smooth open/close animations when not dragging.

### Fix 2 — CSS custom property `--learn-panel-h` (eliminate LearnContentWrapper re-renders)

- Added `useLayoutEffect(() => { document.documentElement.style.setProperty("--learn-panel-h", h) }, [panelHeight, isPanelOpen])` in `LearnFretboardPanel`. `useLayoutEffect` fires synchronously before
  browser paint — both panel height and content wrapper padding update in the same frame.
- `LearnContentWrapper` in `learn-layout.tsx` now uses `style={{ paddingBottom: "var(--learn-panel-h, 48px)" }}`
  **instead of subscribing to the Zustand store**. This eliminates all re-renders of `LearnContentWrapper`
  (and the `MemoizedOutlet` → card list tree) during drag and on panel open/close.
- Removed `useLearnFretboardStore` import and `COLLAPSED_PANEL_HEIGHT` constant from `learn-layout.tsx`.
- Added `transition-[padding-right,padding-bottom] duration-300 ease-out` to the content wrapper so
  padding changes animate smoothly.

### Fix 3 — Instant ring selection feedback on cards

- `chord-item-card.tsx`: changed `transition-[box-shadow,border-color]` → `transition-[border-color]`
  so `ring-2` (which is CSS `box-shadow`) appears instantly on click with no animation delay.
- `family-chord-card.tsx`: same change.
- `interval-learning-card.tsx`: already only transitioned `border-color`, no change needed.

## Files Changed

- `app/routes/components/learn-fretboard-panel.tsx` — drag logic overhaul, useLayoutEffect, panelRef, rafRef
- `app/routes/learn-layout.tsx` — LearnContentWrapper uses CSS var, no Zustand subscription
- `app/routes/chord/components/chord-item-card.tsx` — instant ring transition
- `app/routes/family/components/family-chord-card.tsx` — instant ring transition
