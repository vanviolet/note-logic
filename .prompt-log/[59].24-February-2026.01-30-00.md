## Prompt
1. Fix fret input: when fret is already 24 and user types 5, it should change to 5 (not stay at 24)
2. Integrate all possible alphaTeX effects: h, nh, tr, v, vw, f, fo, vs, d, dd, su, sd, pm, lr, s, x (dead note), b (bend)

## Point OF AI Response

### Fret Input Fix
The sequential digit input logic had a bug: when appending digits made the value exceed 24, it clamped to 24 instead of starting fresh with just the typed digit. Fixed by changing `Math.min(24, raw)` to `raw > 24 ? digit : raw`. Now typing 5 when fret=24 gives 5 (since 245 > 24 → use digit 5 alone).

### alphaTeX Effect Integration
**Already working** (via beatEffect select + noteEffect select):
- `{h}`, `{nh}`, `{tr}` — note effects
- `{v}`, `{vw}`, `{f}`, `{fo}`, `{vs}`, `{d}`, `{dd}`, `{su}`, `{sd}` — beat effects

**Now integrated** (via technique toggle buttons in popover):
- `{pm}` Palm Mute — beat-level, emitted as additional beat effect token
- `{lr}` Let Ring — beat-level, emitted as additional beat effect token
- `{s}` Staccato — beat-level, emitted as additional beat effect token
- `{x}` Dead Note — replaces fret with `x` in alphaTeX output, shows "X" in grid
- `{b (0 4 0)}` Bend — default full bend (up-hold-down), emitted as note effect

### Architecture
- **Beat-level effects** (pm, lr, s): applied to ALL notes in the same beat when toggled, matching alphaTeX semantics
- **Note-level effects** (dead, bend): applied per individual note
- **Combinable**: pm/lr/s toggles can combine with the beatEffect select (e.g. dotted + palm mute = `{d pm}`)
- **noteToAlphaTexToken** now builds effect arrays and joins them, supporting multi-effect output
- **Chord output** updated too: per-note effects (dead/bend) on individual chord notes, beat effects from first note
