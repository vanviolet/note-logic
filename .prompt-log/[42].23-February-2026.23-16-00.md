## Prompt
Lanjutkan lengkapkan fitur, selengkap mungkin saya ingin editor ini menjadi editor pro, kemudian audio juga perhatikan soalnya saya coba ketika play di aplhatab aneh suaranya

## Point OF AI Response
- Menambahkan fitur editor level pro:
  - Undo / Redo (dengan shortcut `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, `Ctrl/Cmd+Y`).
  - Copy Bar dan Paste Bar ke bar aktif.
  - Transpose note terpilih `-1/+1` semitone.
- Menambahkan history stack internal untuk perubahan note agar alur editing non-destruktif.
- Integrasi kontrol baru ke bottom bar.
- Perbaikan audio alphaTab yang terdengar aneh:
  - Mengubah soundfont ke `sonivox.sf3` untuk playback browser yang lebih stabil.
  - Menonaktifkan metronome dan count-in default (`metronomeVolume = 0`, `countInVolume = 0`).
  - Menyetel `masterVolume` default lebih aman (`0.9`).
- Perbaikan kualitas data AlphaTex agar playback/pitch lebih benar:
  - Urutan tuning diubah menjadi `E4 B3 G3 D3 A2 E2`.
  - Menambahkan metadata `\ts <beatsPerMeasure> 4` agar time signature sesuai setting editor.
  - Menetapkan instrumen track ke `Acoustic Guitar (steel)`.
- Validasi akhir: tidak ada error di folder `app/routes/studio`.
