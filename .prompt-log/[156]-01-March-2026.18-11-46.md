## Prompt
Analyze ALL the music theory data files to identify master data entities, duplicate data, missing relationships, and constants defined in multiple places. Read all 11 core files and search for color/diagram patterns.

## Point of AI Response

### Complete Audit of Music Theory Data Layer

**Files Analyzed**: 11 theory-music + shared files, plus grep across entire codebase.

**Key Findings**:

1. **Chromatic note arrays duplicated 4+ times**: `NOTES` (music.tsx), `NOTE_NAMES_SHARP` (music.ts), `NOTE_NAMES` (studio-utils.ts), `_NOTES_SHARP` (chord-voicing-engine.ts) — all identical `["C","C#","D",…,"B"]`.

2. **`BASE_PC` map duplicated 4 times**: fretboard.tsx, ukulele-fretboard.tsx, studio-utils.ts, plus inline `baseMap` in music.tsx's `rootToPc()`.

3. **`NOTE_INDEX` map duplicated 4 times**: chord-voicing-engine.ts, piano-chord-diagram.tsx, ukulele-voicing-engine.ts, exercise-data.ts — all doing what `rootToPc()` already does.

4. **Note color maps duplicated 3+ times with inconsistent colors**: `NOTE_COLOR_CLASSES` (fretboard) and `UKE_NOTE_COLOR_CLASSES` (ukulele) are byte-for-byte identical. `NOTE_DOT_COLOR_CLASS` (studio) uses a *different* color mapping (C=red vs C=pink, E=yellow vs E=blue).

5. **`CadentialStrength` type defined in 2 files**: chord.tsx and family.tsx.

6. **`Degree` types incompatible across 3 files**: chord.tsx has 37-value `DegreeToken`, scales.tsx has 16-value `Degree` (includes `b4`), family.tsx has 6-value inline union.

7. **No cross-references between entities**: chords don't link to intervals, scales reference chords by string not typed key, songbook chords are plain strings, dictionary has no links to computable entities.

8. **`degreeColor()` appears unused** — no imports found anywhere in the project.

9. **Diagram components misplaced**: ChordDiagram, PianoChordDiagram, UkuleleChordDiagram live in `routes/songbook/components/` but are used by Chord Explorer route.
