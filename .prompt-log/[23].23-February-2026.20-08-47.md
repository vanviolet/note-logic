## Prompt
Lanjut buatkan halaman tuner, buat tampilan menarik munkin ada tampilan seperti meteran gitu, dan juga untuk fungsi tuning nya harus smooth agar menjadi fitur tuner pro

## Point OF AI Response
- Menambahkan route baru halaman tuner dengan UI modern dan konsisten dengan shell aplikasi (header/background/footer).
- Membuat meter tuner bergaya analog (needle + tick cents) dengan status realtime: `In Tune`, `Tune Up`, `Tune Down`.
- Menambahkan mode `Auto Detect String` dan `Manual Target` untuk string gitar standar.
- Menggunakan pipeline mic pitch yang sudah ada (`useLiveGuitarPitch`) dan mengatur parameter agar lebih stabil untuk tuning gitar.
- Menambahkan smoothing visual berbasis `requestAnimationFrame` supaya pergerakan meter halus (pro feel) tanpa jitter kasar.
- Menambahkan panel kontrol, tombol start/stop tuner, reset meter, confidence/stability bar, dan tips penggunaan.
- Menambahkan navigasi `Tuner` ke menu utama agar fitur mudah diakses.
