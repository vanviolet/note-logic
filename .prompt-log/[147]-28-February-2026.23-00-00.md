## Prompt
- Tampilan masih berantakan, masih ada bekas sidebar panel, dan bottom panel fretboard
- Hilangkan filter families dan quality, kemudian filter root menjadi radio card tapi kecil saja
- Input freetext masih ada bug ngelag ketika mengetik
- Sort: chord C major di pertama dan C minor di kedua, karena ini chord paling sering dicari orang awam

## Point OF AI Response

### 1. Sidebar & Bottom Panel Removed
Chord routes dipindahkan keluar dari `learn-layout.tsx` di `routes.ts`. Sebelumnya chord berada di dalam `layout("routes/learn-layout.tsx", [...])` yang menambahkan `LearnFretboardPanel` (bottom panel) dan sidebar padding. Sekarang chord `...prefix("chord", [...])` berada sejajar dengan nolopedia/songbook — tanpa layout wrapper tambahan.

### 2. Family & Quality Filters Removed
Select dropdown untuk Family dan Quality dihapus dari `chord/index.tsx`. Import `CHORD_FAMILIES`, `CHORD_QUALITIES`, `FAMILY_LABELS`, `QUALITY_LABELS`, dan shadcn `Select` component dihilangkan. Loader dan client-side filtering sekarang hanya menggunakan `root` dan `q` (text search).

### 3. Root Filter → Radio Cards
Dropdown Select untuk root diganti dengan inline radio-card buttons. Setiap button menampilkan root note + count, dengan styling aktif (primary bg) saat dipilih. Klik tombol yang sudah aktif akan toggle kembali ke "All". Layout menggunakan `flex-wrap` sehingga responsif di mobile.

### 4. Search Input Lag Fixed
Bug: Input value terikat langsung ke `searchParams.get("q")` → setiap keystroke memicu `setSearchParams` → URL update → full component re-render.
Fix: Menggunakan `localQuery` state lokal untuk input value, dan `debounceRef` (300ms) untuk URL update. URL hanya diupdate setelah user berhenti mengetik. Juga ada sync balik dari URL → local saat navigasi (back button).

### 5. Sort: C Major First, C Minor Second
Root sort berubah dari `localeCompare` (alphabetical: A→B→C) menjadi chromatic order starting from C. Ditambahkan `ROOT_SORT_ORDER` record dan `getRootSortWeight()` export di `chord.tsx`. Dipakai di `ALL_CHORDS` static sort dan `sortChords()` di `chord-utils.ts`. Hasilnya: C, Cm, Cdim, Caug, C5, ... → C#, C#m, ... → D, Dm, ...

### Files Changed
- `app/routes.ts` — Moved chord prefix out of learn-layout
- `app/routes/chord/index.tsx` — Removed family/quality filters, added radio cards, fixed search lag
- `app/routes/chord/lib/chord-utils.ts` — Updated sortChords to use getRootSortWeight
- `app/theory-music/chord.tsx` — Added ROOT_SORT_ORDER, getRootSortWeight(), updated ALL_CHORDS sort
