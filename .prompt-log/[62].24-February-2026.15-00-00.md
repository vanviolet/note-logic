### Fix: Statistical Grid Resolution

Replaced the `minPlaybackDuration` (strict minimum) approach with a **distribution-based bucketing** system:

- Count beats at each subdivision level using midpoint boundaries (quarter≥720, eighth≥360, sixteenth<360)
- Only use sixteenth-note grid if >20% of beats are that short
- Otherwise use eighth-note grid if any eighth-level beats exist
- Fallback to quarter-note grid

For Canon: ~95% of beats are eighth notes (pd≈480), only ~5% are sixteenth-ish → eighth-note grid → **8 steps per bar** ✓
