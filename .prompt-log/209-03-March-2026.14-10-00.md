## Prompt
Research workspace for: GuitarTab/guitarTabs usage, AlphaTeX patterns, ScaleInstance property consumption, chord.tsx interface structure, and fingering-related interfaces.

## Point OF AI Response

1. **GuitarTab is dead data** — Defined and populated in `scales.tsx` (`ScaleInstance.guitarTabs`) but never imported or consumed by any route or component file. No file outside `scales.tsx` references `GuitarTab`, `guitarTabs`, or `.tabs` on a scale object.

2. **AlphaTeX has two usage contexts** — (a) Knowledge article widgets using `alphatex-player` type with inline `tex` strings (world-music-systems.ts, psychology-of-music.ts), rendered by `AlphaTexPlayerWidget`. (b) Studio module for interactive score editing/playback with `AlphaTabApiLike`, `alphaTex` state, and export functionality.

3. **ScaleInstance is never imported externally** — Only `getScalesMaster()` is imported by `$chordId.tsx` for cross-referencing chord formulas with scale data. No route renders ScaleInstance properties like `guitarTabs`, `songExamples`, etc.

4. **Chord.tsx uses degree-based voicings, not tabs** — `RecommendedVoicings` provides `DegreeToken[][]` per register (low/mid/high) for piano/guitar/bass. No GuitarTab-style fret data exists in ChordEntry.

5. **Piano fingering system is mature; guitar fingering is absent** — `piano-fingering.ts` has full auto-assignment logic (`getPianoRHFingering`, `getPianoLHFingering`) used across chord and songbook routes. No equivalent guitar fingering generator exists. The `GuitarTab` interface stores static position data but lacks algorithmic generation.
