## Prompt
Buat ruler row clickable agar playhead berpindah ke kolom yang diklik (seperti di alphaTab). Tampilkan note name pada fret button, misal di row E fret 5 tampil "5(A)".

## Point OF AI Response

### 1. Clickable Ruler Row
- Ruler cells diubah dari `<div>` menjadi `<button>` dengan hover state (border-primary, bg-primary/10)
- Non-first beats sekarang menampilkan nomor beat (beat+1) agar lebih informatif
- Click handler memanggil `seekToBeat(measure, beat)` yang mengakses alphaTab score model untuk mendapatkan `absolutePlayStart` tick dan set `api.tickPosition`
- Playhead state (`setPlayheadBeat`) juga di-update secara lokal

### 2. Note Name Display
- Added `fretToNoteName(openStringNote, fret)` utility di `studio-utils.ts`
- `GridCell` menerima prop `openStringNote` dan menampilkan format `5(A)` pada note button
- Font size diturunkan ke `text-[11px]` dan padding ke `px-1.5` agar label muat
- `aria-label` juga diperkaya: "Note fret 5 (A)"

- `app/routes/studio/lib/studio-utils.ts` — added `fretToNoteName` export
