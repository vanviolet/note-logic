## Prompt
Tidak rapih, gap terlalu jauh, sidebar tidak perlu rounded/shadow dan harus nempel kanan, behavior mirip header, posisi tombol filter rapih, tambah animasi content saat toggle sidebar, mobile default sidebar tertutup, search text di paling atas pakai InputGroup + icon search, saat data kosong footer berantakan maka footer dipindah ke home saja, dan semua radio button hover cursor pointer.

## Point OF AI Response
- Merapikan `FloatingFilterSidebar`:
  - Hilangkan rounded dan shadow.
  - Sidebar menempel kanan (`right-0`) dengan border kiri + backdrop seperti shell/header style.
  - Lebar diperkecil agar gap konten tidak terlalu besar.
  - Posisi tombol filter diperbaiki dan mengikuti state open/close secara halus.
- Menambahkan animasi transisi konten saat sidebar buka/tutup di route:
  - `Chord`, `Interval`, `Family` memakai `transition-[padding]` + durasi.
  - Padding kanan saat open diperkecil menjadi `lg:pr-80`.
- Mobile default sidebar sekarang tertutup:
  - state awal `false`.
  - auto sync ke desktop terbuka via `matchMedia("(min-width: 1024px)")`.
- Search by text dipindah/ditetapkan di paling atas dan diubah jadi `InputGroup` + icon `Search` pada:
  - Chord controls
  - Interval controls
  - Family controls
- Footer dipindahkan dari shared layout ke Home route saja:
  - Hapus footer dari `site-layout.tsx`.
  - Tambahkan `HomeFooter` di `home/index.tsx`.
- Semua radio button sekarang pointer:
  - `RadioGroupItem` default class ditambah `cursor-pointer`.
  - Label radio di Chord/Interval juga dibuat `cursor-pointer`.
- Semua file terkait sudah divalidasi tanpa error.
