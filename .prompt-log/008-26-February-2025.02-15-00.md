## Prompt
Bagian intro & interlude ini sepertinya kurang gap diantara chord jadi bingung lihatnya. Dan implementasikan transpose, speed auto scroll, kemudian bisakah anda buat tampilan fretboard chord diagram dynamic component untuk semua chord.

## Point OF AI Response

### 1. Fixed Chord Spacing in Chord-Only Lines
- **chord-pro-line.tsx**: Chord-only lines (intro/interlude) now render chords with proper `mr-4` spacing instead of inline-flex column layout. Tail text like "x2" is rendered separately as italic annotation.
- **songbook-utils.ts**: `isChordOnlyLine()` updated to also detect lines with short repeat markers (e.g. `x2`, `x4`).

### 2. Transpose Feature
- **songbook-utils.ts**: Added `transposeChord()` and `transposeKey()` functions supporting all chord types: major, minor, 7th, sus, dim, aug, slash/bass chords. Uses chromatic note mapping with sharp/flat preference based on original root.
- **$songId.tsx**: Added `transpose` state with +/- buttons, current semitone display, and reset button. Key display in info panel updates dynamically. All chords in the sheet and "Chord yang digunakan" section transpose live.
- **section-block.tsx** & **chord-pro-line.tsx**: Accept and pass `transpose` prop through the component chain.

### 3. Auto-Scroll with Speed Control
- **$songId.tsx**: Added auto-scroll using `requestAnimationFrame` for smooth 60fps scrolling. Controls include Play/Pause button and a speed slider (0.3–5x). Scroll speed is delta-time normalized. Auto-scroll stops when navigating between songs.

### 4. Dynamic SVG Chord Diagram Component
- **chord-voicing-data.ts** (new, ~500 lines): Comprehensive chord voicing database with 80+ chord shapes including:
  - All major, minor, 7th, minor 7th, major 7th chords (natural + sharp/flat)
  - sus2, sus4, 7sus4, add9 chords
  - Diminished, augmented chords
  - Slash/inversion chords (C/B, C/E, D/F#, G/B, Am/E, etc.)
  - Power chords (C5, D5, E5, G5, A5)
  - 9th chords
  - Each voicing includes frets, finger numbers, barre positions, and baseFret
- **chord-diagram.tsx** (new): Pure SVG chord diagram component featuring:
  - 6-string × 5-fret grid with proper spacing
  - X (muted) and O (open) markers above the nut
  - Thick nut line for open-position chords
  - Fret position indicator (e.g. "3fr") for barre chords up the neck
  - Filled circles with finger numbers (1-4) inside
  - Barre notation (rounded rectangle across strings)
  - Chord name label above the diagram
  - Fallback display for chords without voicing data
  - Theme-aware colors using CSS variables (fill-foreground, stroke-border, etc.)
  - Responsive width prop with auto-calculated aspect ratio

### 5. Integration
- Chord diagrams replace the plain text chord badges in the "Chord yang digunakan" section
- Transpose + auto-scroll toolbar sits between the info panel and chord diagrams
- All features respect dark/light mode via theme tokens
- Zero TypeScript/lint errors across all modified and new files
