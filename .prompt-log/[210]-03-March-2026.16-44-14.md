## Prompt

## Point OF AI Response

- **Loader**: Validates `scaleType` via `getScaleSpec()`, throws 404 if not found. Computes prev/next scale navigation. Resolves related scales by matching names to keys.

- **UI Sections**: Breadcrumb → Hero header (back link, icon, h1, notes, badges, description) → Root selector buttons → Composed notes display → 2-col grid (Scale Anatomy left, Learning Content right) → Piano Fingering → Guitar Positions → Song Examples → Related Scales (link grid) → Prev/Next navigation.
