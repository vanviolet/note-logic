## Prompt
Coba baca documentasi react router v7 yang tersedia di .github/docs/react-router-v7 dan apakah bisa di react router v7 ssr ini membuat fungsi insert tapi database nya dalam bentuk json saja

## Point OF AI Response

**Ya, React Router v7 SSR fully mendukung operasi insert dengan JSON file sebagai database.**

Key findings dari dokumentasi:

1. **`loader` (server-only)** — digunakan untuk membaca data dari JSON file via `fs.readFile`. Fungsi ini dihapus dari client bundle sehingga aman menggunakan Node.js APIs.

2. **`action` (server-only)** — digunakan untuk operasi insert/write ke JSON file via `fs.writeFile`. Setelah action selesai, React Router otomatis me-revalidate semua loader data sehingga UI langsung sync.

3. **`.server.ts` modules** — Disarankan membuat utility baca/tulis JSON di file `.server.ts` (misal `json-db.server.ts`) agar build gagal jika secara tidak sengaja di-import di client.

4. **Perhatian**: JSON file tidak punya locking mechanism, sehingga bisa terjadi race condition pada concurrent writes. Cocok untuk dev/prototype, tapi production sebaiknya gunakan SQLite/Prisma.

5. **Project sudah siap** — `react-router.config.ts` sudah mengatur `ssr: true`, sehingga loader dan action sudah berjalan di server.
