## Prompt
Search the workspace for alphaTab type definition file (d.ts) containing Beat class and MasterBar class definitions. Find exact properties: playbackStart, absolutePlaybackStart, playbackDuration, duration, dots, displayStart, absoluteDisplayStart on Beat, and start on MasterBar.

## Point OF AI Response
Found all relevant type definitions in `node_modules/@coderline/alphatab/dist/alphaTab.d.ts`.

### Key findings:
1. **`beat.playbackStart`** and **`beat.displayStart`** are **bar-relative** (offset within the current bar in midi ticks), NOT absolute.
2. **`beat.absolutePlaybackStart`** and **`beat.absoluteDisplayStart`** are **computed getters** that return absolute positions across the whole score.
3. **`masterBar.start`** is the **absolute** timeline position of the bar within the whole score (midi ticks).
4. The relationship is: `absolutePlaybackStart = masterBar.start + beat.playbackStart`.
5. **`beat.duration`** is of type `Duration` (enum: Whole=1, Half=2, Quarter=4, Eighth=8, etc.), NOT a tick value.
6. **`beat.playbackDuration`** and **`beat.displayDuration`** are in midi ticks.
7. **`beat.dots`** is a plain number (0, 1, 2, etc.).
8. `BeatTickLookup` has its own `start`/`end` which are absolute tick positions used for cursor/playback synchronization.
