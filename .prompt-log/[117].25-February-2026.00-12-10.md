## Prompt
z Index tooltip sepertinya di belakang interactive window

## Point OF AI Response
Tooltip memang kalah layer karena default `z-50`. Saya naikkan z-index global komponen tooltip di UI primitives:
- `TooltipContent`: `z-120`
- `TooltipPrimitive.Arrow`: `z-120`

Perubahan ini membuat tooltip tampil di atas interactive/floating window pada halaman Studio.
