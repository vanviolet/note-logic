## Prompt
ada bug sepertinya ketika preview panel di resize sampai hilang , music note alpha tab juga ikut hilang dan tidak kembali lagi

## Point OF AI Response
- Identified root cause: alphaTab host element was conditionally unmounted when preview height became very small, so renderer lost its DOM mount target.
- Fixed by keeping alphaTab host always mounted in preview panel.
- Added collapsed-state visual behavior with `opacity-0` + `pointer-events-none` when height is very small, without unmounting renderer host.
- Result: collapsing preview no longer destroys the rendered notation, and expanding panel restores visible notes properly.
- Validation passed: no errors in updated component.
