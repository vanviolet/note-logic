## Point of AI Response

### 1. Fretboard Loading Skeleton

**File:** `app/routes/components/learn-fretboard-panel.tsx`

Added `FretboardSkeleton` component above `LearnFretboardPanel`. The skeleton exactly mirrors the
real fretboard grid layout:
- Live mic button row (2 skeleton bars)
- Header row (1 + 13 columns matching `gridTemplateColumns: 124px repeat(13, 1fr)`)
- 6 string rows × 13 fret cells each, using opacity variation (0.35 + si * 0.08) for depth
- `Skeleton` from `~/templates/components/ui/skeleton` (existing shadcn component)

The `Suspense` fallback in the panel content was changed from a plain centered div to
`<FretboardSkeleton />`. Also added `import { Skeleton } from "~/templates/components/ui/skeleton"`.

### 2. Active Note Text Color in Light Mode

**File:** `app/templates/components/custom/fretboard.tsx`

`NOTE_COLOR_CLASSES[pc].activeText` was e.g. `text-pink-100` (very light) — invisible on light
backgrounds. Changed `FretButton` `isActive` className block from `noteColor.activeText` to
`"text-foreground"` (CSS var: dark in light mode, light in dark mode). The colored `bg` and `border`
still show the note's pitch-class color; only the text follows the theme foreground.

### 3. Search Params in All 3 Route Filters

**Files:** `chord/index.tsx`, `family/index.tsx`, `interval/index.tsx`

All `useState` filter variables were replaced with `useSearchParams` from `react-router`:

| Route   | Params added |
|---------|-------------|
| /chord  | `q`, `root`, `family`, `quality` |
| /family | `scale`, `root`, `q`, `family`, `cadential`, `view` |
| /interval | `root`, `spell`, `q`, `filter` |

Each setter calls `setSearchParams((prev) => ...)` with `replace: true` for text search (to avoid
history spam). Non-default values are set; default values remove the param to keep URLs clean.
The family `useEffect` that resets root on scale change now also updates the URL.

### 4. Cross-Navigation Buttons on Cards

**Files:** `chord-item-card.tsx`, `family-chord-card.tsx`, `interval-learning-card.tsx`

Each card now has a "View X →" section at the bottom, wrapped in a `div` with `e.stopPropagation()`
to prevent card selection being triggered when clicking nav buttons.

| Card source | Links added |
|-------------|-------------|
| chord-item-card | `/interval?root=<chord.root>` + `/family?root=<chord.root>` |
| family-chord-card | `/chord?root=<rootNote>` + `/interval?root=<rootNote>` |
| interval-learning-card | `/chord?root=<interval.root>` + `/family?root=<interval.root>` |

All links use `prefetch="intent"` for React Router v7 hover-prefetch. The `root` param matches
the key used by each route's `useSearchParams`, so navigation arrives with the filter pre-set.
Button import added to chord and family cards (interval card already had it).
