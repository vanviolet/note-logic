## Point Of AI Response

### Changes in `app/routes/components/learn-fretboard-panel.tsx`

**1. GripHorizontal centered in handle bar**
- Replaced the old flex layout (left: drag lines + Guitar + title | right: badge + toggle) with a **3-column CSS grid**: `grid-cols-[1fr_auto_1fr]`.
- Left column: Guitar icon + title/subtitle.
- **Center column**: `GripHorizontal` icon — always visible whether panel is open or closed, acts as a clear drag affordance.
- Right column: live pitch badge + chevron toggle button.

**2. Drag all the way to bottom (full collapse)**
- Removed `MIN_EXPANDED_HEIGHT = 220` constraint that prevented dragging below 220px.
- Added `SNAP_CLOSE_THRESHOLD = COLLAPSED_HEIGHT + 24` — if the user releases the drag below this height, panel snaps closed.
- Drag is now allowed in **both directions** from both states:
  - **Dragging up from closed**: `handleDragStart` no longer early-returns when `!isPanelOpen`. It starts from `COLLAPSED_HEIGHT` as the base height and calls `openPanel()` when height exceeds the collapsed threshold.
  - **Dragging down to close**: When `rawNext <= COLLAPSED_HEIGHT`, calls `closePanel()` via `useLearnFretboardStore.getState()` (avoids stale closure) and resets height to `COLLAPSED_HEIGHT`.
- Added `openPanel` selector to the store subscriptions.
- `handleDragEnd` uses `useLearnFretboardStore.getState()` to read the latest height/open state at release time (avoids stale closure on snap-close logic).

**3. Sidebar-aware right positioning**
- Imported `useLearnSidebarStore`.
- Panel container changed from `left-0 right-0` to `left-0 right-0` + conditional `lg:right-[300px]` when sidebar is open.
- CSS class: `transition-[right] duration-300 ease-out` — right edge smoothly transitions as sidebar opens/closes (matching the 300ms sidebar animation).
- Result: on lg+ screens, the panel stops at the sidebar's left edge and they sit side-by-side with no overlap.

### No changes to other files
