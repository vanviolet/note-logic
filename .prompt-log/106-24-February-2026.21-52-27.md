## Prompt
- tolong bagian bars juga dibuat sticky header
- column dibuat agar fullwidth saja agar gampang di kliknya
- Di header bar ada aksi dalam bentuk icon saja, untuk add new bar,expand all
- di sub panel bar integrasikan context menu di luar group,bar,column, aksinya yang muncul adalah add new bar, expand all

## Point OF AI Response
### Perubahan utama di panel Bars
1. **Sticky header untuk Bars**
   - Header Bars sekarang sticky (`sticky top-0`) dengan background blur agar tetap terlihat saat scroll.
   - Badge jumlah bar tetap tampil di header.

2. **Aksi icon-only di header**
   - Tambah 2 tombol icon-only:
     - **Add New Bar** (`Plus`)
     - **Expand All** (`ChevronsDown`)
   - Keduanya punya `title` dan `aria-label` untuk aksesibilitas.

3. **Column full-width agar mudah di klik**
   - Tombol row column di tree diubah jadi `w-full` + `text-left` + padding vertikal lebih nyaman,
     sehingga area klik memenuhi lebar panel.

4. **Context menu pada area kosong sub panel Bars**
   - Kontainer utama panel Bars dibungkus context menu tingkat root.
   - Saat klik kanan di area kosong (di luar group/bar/column), menu menampilkan:
     - `Add New Bar`
     - `Expand All`

### Implementasi aksi
- **Add New Bar**: menambah bar baru di bawah bar terakhir (`onAddBarBelow(measureCount - 1)`).
- **Expand All**:
  - Expand semua bar (`onSetExpandedBars([...all index])`)
  - Buka semua column collapse (`onSetCollapsedColumns([])`)
  - Expand semua group yang sedang collapsed (iterasi `barGroups` dan trigger `onToggleGroupCollapsed`).
