## Prompt
- Tampilan detail ketika membuka collapse di table view masih berantakan text melewati card jadi tidak terlihat , sepertinya tidak perlu mnggunakan card dan juga harusnya ketika di resize windownya tetap mobile friendly

## Point OF AI Response
Perbaikan dilakukan pada detail row di Table View agar teks tidak overflow dan tetap rapi saat resize/mobile:

- Menambahkan `whitespace-normal` pada sel detail collapse supaya konten bisa wrap.
- Mengubah breakpoint grid detail dari `md:grid-cols-3` ke `lg:grid-cols-3` agar layout tidak kepadatan di ukuran medium.
- Menyederhanakan blok detail interval (tanpa gaya card berat) agar lebih bersih dan responsif.
- Menjaga konsistensi fix wrapping di table detail route lain (`chord` dan `family`) untuk mencegah bug serupa.
