## Prompt
Buat Editor di timeline lebih interactive: marquee multi-select (klik kiri tahan), context menu (klik kanan), drag bar reorder, arrow key navigation, Ctrl+Arrow duplicate note, performa tetap bagus.

## Point OF AI Response

### New Files
- **`app/routes/studio/hooks/use-studio-grid-interaction.ts`** (~690 lines)  
  Central hook for all grid interactivity:
  - **Marquee selection**: Pointer events on grid → rubber-band overlay → `querySelectorAll("[data-note-btn]")` bounding box overlap → `Set<string>` selectedNoteIds
  - **DOM class toggling**: `useEffect` applies/removes `.studio-multi-selected` via `classList` (no React re-render for 1300+ cells)
  - **Arrow navigation**: Up/Down changes string, Left/Right changes beat with measure wrapping; scrollIntoView
  - **Ctrl+Arrow duplicate**: Clones selected notes offset by direction, ID collision check, bounds check
  - **Copy/paste**: `copiedNotesRef` stores notes; paste with offset from target cell
  - **Bulk actions**: `deleteSelectedNotes`, `selectAllInMeasure`, `clearSelection`, `selectAll`
  - **Bar drag reorder**: Pointer-events based drag on ruler beat=0 cells; `dragBarFrom`/`dragBarOver` state; calls `onReorderMeasure`
  - **Keyboard listener**: Zero-dependency `useEffect` with stable refs for Arrow, Ctrl+C, Ctrl+V

### Performance Strategy
- **Marquee**: Pointer events + RAF overlay, no per-cell React state
- **Multi-select highlight**: DOM `classList` manipulation bypasses React re-renders
- **Arrow nav**: Stable refs in zero-dependency `useEffect` prevent stale closures
- **Bar drag**: Pointer events on ruler cells, `document.elementFromPoint` for hit testing
- **Virtualization**: Existing `VirtualizedChunk` + IntersectionObserver preserved
