## Prompt
- selected hold masih muncul style bawaan
- delete untuk multi selected belum ada (campuran group/bar/column/note)
- semua item harus punya context menu dan aksi beda per tipe/selection

## Point OF AI Response
Perubahan di [app/routes/studio/index.tsx](app/routes/studio/index.tsx):
- Konsistensi style selected:
  - Menambahkan `select-none` di row bar.
  - Menambahkan suppress native selection di sidebar container (`[&_*::selection]:bg-transparent`).
- Multi-delete selection:
  - Menambahkan `deleteSidebarSelection()` untuk menghapus banyak item sekaligus lintas tipe (`group`, `bar`, `col`, `note`).
  - Shortcut `Delete/Backspace` kini:
    - jika multi-select => hapus semua selected,
    - jika single bar => tetap behavior lama (clear notes dulu, jika kosong lalu hapus bar),
    - tipe lain => hapus item aktif.
- Context menu untuk semua item:
  - Bar & Group: tetap ada, ditambah `Delete Selected (N)` saat multi-select.
  - Column: context menu baru (Activate, Collapse/Expand, Clear Column, Delete Selected jika multi).
  - Note: context menu baru (Activate, Delete Note, Delete Selected jika multi).
- Selection state tetap unified via key (`activeSidebarItemKey`, `selectedSidebarItemKeys`) dan shift multi-select dipertahankan.
- Validasi: tidak ada error lint/type pada file yang diubah.
