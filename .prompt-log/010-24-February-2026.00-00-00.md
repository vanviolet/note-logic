## Prompt
Research alphaTab type definitions for `Note`, `Staff`, `Beat` classes and `GraceType` enum in node_modules/@coderline/alphatab/dist/alphaTab.d.ts. Specifically: Note.string indexing, Staff.tuning direction, Beat.playbackStart scope, and GraceType enum values.

## Point OF AI Response 
Findings from alphaTab type definitions:

1. **`Note.string` is 1-based.** String `1` = lowest pitched string on guitar = bottom tablature line.

2. **`Staff.tuning` is HIGH-to-LOW.** Index `[0]` = top tablature line = highest pitched string (opposite direction from `Note.string`). Mapping: `tuning[tuning.length - noteString]`.

3. **`Beat.playbackStart` is bar-relative** (position within current bar in MIDI ticks). Use `Beat.absolutePlaybackStart` for score-absolute position.

4. **`GraceType` enum** has 4 values: `None=0`, `OnBeat=1`, `BeforeBeat=2`, `BendGrace=3`.
