## Prompt
Position selection masih tidak sesuai dengan cursor, kemudian ubah saja tampilan editornya ini jadi workspace nya full 1 kotak selain panel sidebar header, bottom bar, dll, nah jadi sudah bisa trigger selection di mana saja di dalam workspace, tidak perlu menggunakan card timeline grid

## Point OF AI Response

### Root Cause of Marquee Position Mismatch
- `gridContainerRef` was placed on a wrapper `<div>` around `StudioGrid`
- Marquee coordinates were calculated relative to that div (`getBoundingClientRect + scrollLeft/scrollTop`)
- But the marquee overlay was rendered inside `StudioGrid`'s internal `hostRef`, nested deep within `Card > CardContent > div`
- The Card's header, padding, and content offset created a position gap between coordinate origin and render target

### Fix: Unified Coordinate System
- Moved `gridContainerRef` to the `<section>` element (the scrollable workspace area) via a merged ref callback
- Moved marquee overlay rendering to the same `<section>` element
- Now both coordinate calculation and overlay render reference the same DOM node → positions match exactly

### Layout Change: Card Removed, Full Workspace
- **`studio-grid.tsx`**: Removed `Card`/`CardHeader`/`CardContent` wrapper. Grid now renders chunks directly in a simple `<div>` with `space-y-3`. Removed pointer events, marquee overlay, and context menu from this component (moved to parent).
- **`studio-main-content.tsx`**: Section element now handles everything:
  - `ref={mergedRef}` — merges `sectionRef` + `gridContainerRef` onto same node
  - `onPointerDown/Move/Up` — marquee selection works anywhere in workspace
  - `onContextMenu` — right-click context menu anywhere in workspace
  - Marquee overlay as absolute-positioned child of section
  - ContextMenu wraps the entire section via `ContextMenuTrigger asChild`
  - Note count + selection count badges moved to status bar strip

### Props Cleanup
- Removed from `StudioGridProps`: `notesCount`, `selectedNoteIds`, `marqueeRect`, `onGridPointerDown/Move/Up`, `onDeleteSelected`, `onCopySelected`, `onPasteNotes`, `onSelectAllInMeasure`, `onSelectAll`, `onClearSelection`
- These are now consumed directly by `StudioMainContent` without passing through to `StudioGrid`

### Files Changed
1. `app/routes/studio/components/studio-grid.tsx` — removed Card wrapper, pointer events, marquee, context menu
2. `app/routes/studio/components/studio-main-content.tsx` — section-level pointer events, marquee, context menu, merged ref
